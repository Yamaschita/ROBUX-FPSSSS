# Project Velocity (ROBUX FPSSSS)

Bem-vindo ao repositório do jogo FPS Web Multiplayer! 

A infraestrutura inicial usará as seguintes tecnologias:
- **Frontend**: Three.js + Vite
- **Backend (Multiplayer)**: Node.js + Colyseus
- **Física**: Rapier3D

O plano detalhado de implementação encontra-se no plano interativo do assistente. Aguardando aprovação para iniciarmos a geração dos arquivos de configuração e código inicial.
